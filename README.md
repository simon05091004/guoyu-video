# 康軒六年級國語影音庫

康軒版國小六年級國語每一課的 YouTube 補充影片索引。
21 課、139 支連結，全數以 YouTube oembed 逐支驗證可播放（2026-09-02）。

- 線上版：https://simon05091004.github.io/guoyu-video/
- 成品：[`index.html`](index.html) —— 單一 HTML、零外部相依（只用 Google Fonts），可直接 GitHub Pages 出。
- 維護腳本：[`tools/`](tools/)（抓課次生字、搜新片、驗連結、重建頁面），流程見 [`tools/README.md`](tools/README.md)。

## 內容

每一課分兩組：**課本直搭**（照康軒課次拍的朗讀、導讀、語詞修辭、完整課堂）與
**延伸補充**（課文背後的地方、人物、成語、文體寫作）。
另有學期切換、全文搜尋、分類篩選、5 分鐘內快篩、收藏、深淺色與列印版。

## 課次注意事項

- 六上（第十一冊）12 課。**115 學年度第十二課由〈祕密花園〉換成〈橘子〉**，其餘與 114 學年度相同。
- 六下（第十二冊）**自 113 學年度改版後為 9 課**（舊版 11–12 課）。網路上多數六下影片仍是舊版課次，
  本庫一律**對課名不對課次**。
- 文體標記是依課名與生字判讀的，非官方分類。
- 影片皆為他人上傳的公開內容，可能隨時下架；每張課卡都附「在 YouTube 搜這一課」作為退路。
