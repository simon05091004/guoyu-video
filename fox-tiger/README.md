# 狐假虎威 字音字形大挑戰 · Sounds & Shapes Quiz

六上第八課〈狐假虎威〉的字音字形搶答遊戲。玩法和第六課〈珍珠奶茶〉一樣：
學生用平板掃 QR code 就能玩，不用安裝 App、不用登入。題目照課本「字音字形」的七組字出。

- **投影頁（老師）**：[`host.html`](host.html) — QR code、房號、選關與即時排行榜
- **遊戲（學生）**：[`index.html`](index.html) — 平板掃碼後開啟的頁面

## 內容

34 題，八關。第一到第七關對照課本的 ①～⑦，第八關把七組字混在一起考：

| 關卡 | 字組 | 讀音 | 題數 |
| --- | --- | --- | --- |
| 一 | 寓・遇 | 都唸 ㄩˋ（寓言、寓意／禮遇、待遇） | 4 |
| 二 | 赫・嚇 | 赫 ㄏㄜˋ；嚇 ㄒㄧㄚˋ（驚嚇、嚇人）／ㄏㄜˋ（恐嚇、嚇阻） | 4 |
| 三 | 遂・逐 | 遂 ㄙㄨㄟˋ（順遂、未遂）；逐 ㄓㄨˊ（競逐、追逐） | 4 |
| 四 | 諷・楓 | 諷 ㄈㄥˋ（諷刺、嘲諷）；楓 ㄈㄥ（楓樹、楓葉） | 4 |
| 五 | 蔽・幣・弊 | 都唸 ㄅㄧˋ（蒙蔽、掩蔽／錢幣、硬幣／弊案、利弊） | 4 |
| 六 | 妨・仿・彷・訪 | 妨 ㄈㄤˊ；仿、彷、訪 ㄈㄤˇ（不妨／模仿／彷彿／拜訪） | 5 |
| 七 | 誘・透 | 誘 ㄧㄡˋ（誘導、引誘）；透 ㄊㄡˋ（透明、透氣） | 4 |
| 八 | 綜合挑戰 | 找錯字、比讀音 | 5 |

題型有四種：

- **看注音選國字**：「ㄩˋ言」的 ㄩˋ 是寓、遇、喻還是預？干擾選項都是同音字或長得像的字。
- **看國字選注音**：「恐嚇」的「嚇」怎麼唸？
- **配對**：蒙＿／硬＿／利＿ 配上 蔽／幣／弊；不＿／模＿／＿彿／拜＿ 配上 妨／仿／彷／訪。
- **找錯字**、**是非題**。

答案選項用大字楷書顯示（Google Fonts 的霞鶩文楷，連不到時改用電腦內建的標楷體），跟課本字形一致，
筆畫差異（蔽／幣／弊下半部、遂比逐多兩點）看得清楚。每一題答完都有解析，說明部首和字義怎麼分，
例如「楓是樹，所以是木部；諷是用說的，所以是言部」。

少數題目連到課文：寓言、寓意、諷刺仗勢欺人、狐狸蒙蔽老虎、百獸被嚇跑，以及《戰國策》原文
「虎以為然，故遂與之行」的「遂」。

和珍珠奶茶一樣是中英雙語，每題附一行英文。英文在「看注音選國字」題會寫出拼音（反正題目已經給了讀音），
在「看國字選注音」題則不寫拼音，以免洩漏答案。

## 即時全班排行榜

和 `../bubble-tea/` 共用同一個 Firebase 專案，[`firebase-config.js`](firebase-config.js) 已經填好，
不用另外設定。房號是各自隨機產生的，兩個遊戲的成績不會混在一起；平板上的偏好與成績也分開存
（這個遊戲用 `fx8.` 開頭的 localStorage，珍珠奶茶用 `bt6.`）。
Firebase 的設定步驟與安全說明見 [`../bubble-tea/README.md`](../bubble-tea/README.md)。

## 要改題目？

題庫在 [`index.html`](index.html) 的「課程內容」區塊（`LESSON CONTENT START` 到 `END`）。
欄位和珍珠奶茶相同，另外多了兩個方便出字音字形題的寫法：

```js
{ r:5, t:'mc', big:'zi', src:'⑤ 蔽・幣・弊 · 字形',
  zh:'撲滿裡裝滿了一元硬ㄅㄧˋ。「ㄅㄧˋ」要寫哪一個字？',
  en:'The piggy bank is full of one-dollar yìngbì (coins). Which character is bì?',
  o:['幣','弊','蔽','斃'],            // 選項可以只寫字串，第一個是答案
  why:['中文解析','English explanation'] }
```

- `big:'zi'` 選項是單一個字，`big:'zy'` 是注音，`big:'wd'` 是詞語：三種都用大字楷書。
- 配對題的左欄用「＿」代表要填的字（例如 `'蒙＿'`），解析會自動顯示成「蒙蔽」。
- 改了關卡名稱或題數，記得也改 [`host.html`](host.html) 裡的 `ROUNDS`（投影頁的選關按鈕）。

作答時間：單選 20 秒、是非 15 秒、配對 45 秒。改完存檔、推上去就好，沒有建置步驟。
